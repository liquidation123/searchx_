How to explore

Drag to move across the sky. Use + and − to zoom. Use Return to go back to your last target at its original zoom.

SPHEREx sees infrared light our eyes can’t see. Pick a wavelength to see which features stand out. Each setting shows a different wavelength of the same sky survey.

Select a labeled pin to learn about the object, or try one of these objects.
